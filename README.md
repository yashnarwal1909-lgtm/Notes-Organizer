# Notes Organizer

## Project Description
Notes Organizer is a beginner-friendly Python project that helps students manage their study notes easily.

## Features
- Add new study notes
- View all saved notes
- Edit existing notes
- Organize notes by subject
- Search notes by title, subject, or content
- Save notes in a JSON file

## Technologies Used
- Python
- JSON
- Git and GitHub
- Visual Studio Code

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```

## Project Purpose
This project helps students organize their notes and demonstrates basic Python programming, functions, file handling, lists, dictionaries, and searching.
